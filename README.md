A core mod adding a few items and blocks, serving as the foundation for addons.

Current features:
- Ajifurai (food)
    - It is an excellent food that keeps you full.
- Better Fish (food)
    - When baked it becomes Ajifurai.
- Pedestal block
    - You can display items in three dimensions.

複数のアイテムやブロックを追加するModで、アドオンの基盤となるModとして機能します。

現在の追加要素:
- アジフライ（食べ物）
    - 腹持ちの優れた食べ物です。
- バッター液付き魚（食べ物）
    - 焼くとアジフライになります。
- 台座ブロック
    - アイテムを立体的に表示して飾れます。
